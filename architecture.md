## 2. 模块说明

### 2.1 核心交易模块

| 模块 | 功能 | 技术选型 |
|------|------|----------|
| 订单接入 | 接收客户彭博 EMSX 下单 | Bloomberg EMSX API (blpapi) |
| 订单处理 | 验资、风控检查、策略处理 | Spring Boot |
| 下游发送 | 向 Prime Broker 发送订单 | Bloomberg EMSX API |
| 成交回报 | 接收成交回报，异步处理 | Bloomberg API + 消息队列 |

### 2.2 管理后台

| 模块 | 功能 |
|------|------|
| 客户管理 | 客户信息维护 |
| 资金管理 | 客户资金额度配置 |
| 持仓管理 | 客户持仓查询 |
| 白名单管理 | 允许交易的合约/标的 |

### 2.3 监控模块

| 模块 | 功能 |
|------|------|
| 订单监控 | 实时订单状态、成交量统计 |
| 通道状态 | Bloomberg 连接状态 |
| 系统健康 | CPU、内存、线程、数据库连接 |

## 3. 数据流

```
客户下单 ──▶ 订单接入 ──▶ 验资/风控 ──▶ 策略处理 ──▶ 下游发送 ──▶ Prime Broker
                 │                              │
                 ▼                              ▼
           订单入库                      成交回报处理
                 │                              │
                 ▼                              ▼
           PostgreSQL                    PostgreSQL + 推送管理后台
```

## 7. 关键设计说明

1. **高稳定性**：核心交易链路无单点，支持多实例部署
2. **消息队列解耦**：订单处理和成交回报通过消息队列异步处理，避免阻塞
3. **前后端分离**：管理后台和监控界面独立部署
4. **Bloomberg EMSX 适配**：统一封装 Bloomberg API，对内提供标准化接口
